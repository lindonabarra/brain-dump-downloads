# Brain Dump downloads

A little space for a busy mind. Brain Dump brings task planning, sticky notes,
checklists, and per-task whiteboards together in a personal desktop workspace.
Your work is saved locally on your device.

## What is here?

This public repository hosts installer releases, checksums, and download notes.
The app and website source are maintained separately in a private repository.

Brain Dump is a local, personal workspace. It does not currently provide cloud
sync or live collaboration. Export and import backups to move between devices.
